# 密涅瓦思考包 | Minerva Mind

基於密涅瓦大學（Minerva University）決策科學的問題分析工具。免費、開源、無需註冊。

## 功能

1. **問對問題框架** - 用現況、目標、障礙、限制四要素精準定義問題
2. **76 個思考習慣** - 涵蓋批判性思考、創意思考、有效溝通、有效互動
3. **智慧推薦** - 根據問題描述自動匹配最適合的思考習慣
4. **問題規格書** - 自動產生結構化的問題分析文件
5. **AI 提示詞生成** - 產出可直接貼入任何免費 AI 的提示詞

## 密涅瓦思考框架

### 四大類別

| 類別 | 說明 |
|------|------|
| 批判性思考 | 系統性分析和評估資訊，排除偏誤 |
| 創意思考 | 運用創造性方法解決問題 |
| 有效溝通 | 清晰精準地傳達想法 |
| 有效互動 | 在複雜環境中協作、談判和領導 |

### 問對問題四要素

- **現況** - 目前發生了什麼
- **目標** - 你想達成什麼
- **障礙** - 可以改變的阻礙因素
- **限制** - 不可改變的條件

### 決策科學三要件

1. 可檢驗 - 決策過程可被攤開檢視
2. 可複製 - 成功方法可被重複使用
3. 可優化 - 根據回饋持續改善
